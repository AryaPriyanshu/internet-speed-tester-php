# ⚡ Internet Speed Tester

A PHP-based web application that measures browser-based internet connection performance and presents the results through a clean, responsive dashboard.

## 🚀 Features

- Measures connection latency
- Estimates download speed
- Estimates upload speed
- Automatically evaluates connection quality
- Stores and displays recent test results
- Responsive dark-themed interface
- PHP backend endpoints for network measurements
- JavaScript-powered asynchronous testing

## 🛠️ Technologies Used

- PHP
- JavaScript
- HTML5
- CSS3
- Fetch API
